# Здоровье ИИ — Telegram-бот

Бот принимает голосовые, фото еды и текстовые сообщения, распознаёт их
через OpenAI и записывает данные в Google Таблицу.

## Установка

1. Установи Python 3.10+
2. `pip install -r requirements.txt`
3. Скопируй `.env.example` в `.env` и заполни значения
4. Положи `service_account.json` (ключ сервисного аккаунта Google) в папку
5. Запусти: `python bot.py`

## Как пользоваться

- **Голосовое**: «вес 82.5», «позавтракал овсянкой», «спал 7 часов»
- **Фото еды**: бот распознает блюдо и КБЖУ
- **Текст**: то же, что и голосом

Бот пишет данные в листы: Питание, Тренировки, Показатели тела,
Сон и вода, Самочувствие.
